# とどけ！こいぶみ 〜ふーさんたちの お城でドキドキ大作戦〜

ブラウザで遊べる推理カードゲームです（ふらっとgames／制作 watg）。
金井 定司 作『ラブレター』の**公式ルールどおり**に作ったファン制作版です。舞台は中世のお城で、役名・絵・説明文はすべてオリジナルです。

- **ルール**：第2版（21枚・2〜6人、最初に選ばれているルール）、クラシック（16枚）、はじまりの16枚（日本のオリジナル版）の3つ。詳しくは [RULES_NOTES.md](RULES_NOTES.md) を見てください。
- **遊び方**：ひとりで CPU と（CPU は最大5人）、またはオンラインで2〜6人。オンラインは部屋コード・招待URL・QR コードで集まり、PeerJS（P2P、STUN のみ）でつなぎます。ホストがゲームを進め、ほかの人の手札は参加者に送りません。
- **CPU**：ふーさん🐻・ミミ🐰・ロボミ🤖・ニャコ😺・ポチ太🐶・コンタ🦊。強さは 弱い／普通／強い／アストラウルトラ😎 から選べます。
  - CPU は**ズルをしません**。見えている情報（捨て札・自分の手札・自分が見たカード）だけで考えます。
  - 強い：残りのカードを数え、相手の出し方から手札を推理します（ベイズ推定）。
  - アストラウルトラ：推理した手札の候補からありえる場面を何通りも作り、先まで読んで手を選びます（確定化モンテカルロ探索）。
- `?from=portal` を付けて開くと「🏠 ひろばへ」ボタンが出ます（ゲーム中は隠れます。⋯ メニューからも行けます）。

## ファイル
`index.html`（画面・CSS）、`logic.js`（ルールと AI、Node でも動きます）、`weights.js`（自己対戦で調整した値）、`chars.js`（キャラクターのセリフ）、`core.js`（役名・共通の部品）、`host.js`（ホストの進行）、`net.js`（通信）、`ui.js`（表示）、`app.js`（操作）、`fx.js`・`audio.js`・`bgm.js`（演出・音）。

## テスト
```
node test/logic.test.js          # ルール・漏れ防止・AI の公平さ（127件）
node test/sim.js                 # CPU 同士の勝率（並列、数分かかります）→ test/sim-report.json
node tools/train.js 60 6000      # β と「強い」の重みの調整 → weights.js
node test/stun-server.js <ip> 3478 & python3 -m http.server 8931 &
node test/e2e.js <ip> 8931       # 画面のテスト（ひとり用 390×844／375×667、オンライン2画面）→ screenshots/
```
